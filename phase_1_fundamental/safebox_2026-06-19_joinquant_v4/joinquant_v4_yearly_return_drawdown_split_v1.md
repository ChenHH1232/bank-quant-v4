# JoinQuant V4 Yearly Return Drawdown Split V1

## Goal

- Split the JoinQuant backtest into annual windows
- Compare `primary` and `benchmark` by yearly return and yearly max drawdown
- Reuse the existing May rebalance boundaries from the V4 annual attribution files

## Input

- Fill `joinquant_v4_daily_nav_input_template.csv`
- Required columns:
  - `date`
  - `line`
  - `nav`

## Expected Input Shape

- One row per trading date per line
- `line` should be either `primary` or `benchmark`
- `nav` should be cumulative strategy net value, for example:
  - first day `1.0000`
  - later day `1.0342`

## Window Rule

- 2021 window: `2021-05-31` to the day before the next May rebalance
- 2022 window: next May rebalance to the day before the following May rebalance
- and so on

This matches the current annual strategy refresh rhythm better than plain calendar-year slicing.

## Script

- Run:

```python
python D:\hh\codex\v4\phase_1_fundamental\build_joinquant_v4_yearly_return_drawdown_split.py
```

## Outputs

- `joinquant_v4_yearly_return_drawdown_split_v1.csv`
  - per line, per annual window metrics
- `joinquant_v4_yearly_return_drawdown_comparison_v1.csv`
  - yearly `primary` vs `benchmark` return and drawdown gaps
- `joinquant_v4_yearly_return_drawdown_report_v1.md`
  - short readable summary generated by the script
