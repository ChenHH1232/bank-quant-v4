# V4 Three-Phase Plan

## Phase 1

- Fundamental data collection
- Fundamental data cleaning
- Fundamental factor construction
- Fundamental-only rolling statistical tests

## Phase 2

- Momentum data collection
- Momentum data cleaning
- Momentum factor construction
- Momentum incremental statistical tests on top of the fundamental baseline

## Phase 3

- Mean-reversion data collection
- Mean-reversion data cleaning
- Mean-reversion factor construction
- Mean-reversion incremental statistical tests on top of the prior baseline

## Principle

- Do not merge all feature families at the start
- Validate each family independently before combining them

## Time Boundaries

- Raw data window: `2013-05-01` to `2026-05-01`
- Research window: `2014-05-01` to `2026-05-01`
- Target backtest window: `2021-05-01` to `2026-05-01`
