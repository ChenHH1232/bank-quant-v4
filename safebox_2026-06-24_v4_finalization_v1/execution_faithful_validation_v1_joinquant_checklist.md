## Reconciliation Order

Stop at the first layer that breaks.

1. pool membership
2. raw factor values
3. standardization
4. sign handling
5. weighted score aggregation
6. ranking and bucket split
7. target weight
8. next-period return mapping

## Typical Failure Sources To Watch

- stock universe mismatch on rebalance date
- factor-date mismatch
- annual report snapshot timing mismatch
- missing-value handling mismatch
- winsorization boundary mismatch
- standardization sample mismatch
- sign direction mismatch
- equal-weight versus IC-weight confusion
- sort tie-breaking mismatch
- top bucket count mismatch after `qcut`
- realized return window mismatch

## Success Criterion

For each chosen date, JoinQuant should match local on:

- the same scored stock list
- the same factor values after standardization
- the same final ranking
- the same top bucket
- the same target weights

Only after that should we investigate why full-period backtest metrics still differ.
